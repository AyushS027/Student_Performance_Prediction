# Student Academic Performance Predictor

A Streamlit app that predicts a student's final grade and estimated overall score.

## Files
- `app.py`: Streamlit dashboard
- `Student_Performance.csv`: dataset
- `requirements.txt`: Python dependencies

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Upload all three files to a GitHub repository, then deploy the repository using Streamlit Community Cloud with `app.py` as the main file.
